# Support

SatQuery is a Smart India Hackathon (SIH26167) student project. There is no
SLA and no official ISRO helpdesk.

## Questions about using or running it

1. Read [README.md](./README.md) (quick start, PROJ_LIB, PowerShell `curl.exe`).
2. Read [docs/api-spec.md](./docs/api-spec.md) for JobView and endpoints.
3. Open a GitHub Discussion or a **question** issue if those do not answer it.

## Bugs and features

Use the [issue templates](https://github.com/amulyagavankar20-glitch/SatQuery/issues/new/choose).

## Architecture changes

Product locks live in
[docs/SatQuery_AI_System_Architecture.md](./docs/SatQuery_AI_System_Architecture.md).
Proposals that add Redis, Kafka, a 30B orchestrator, or a second talking VLM
need an issue **before** a PR — see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Security

Do not file public issues. Follow [SECURITY.md](./SECURITY.md).

## Conduct

[CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) — reports go privately to the
repository owner on GitHub, not the issue tracker.
